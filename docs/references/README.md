# Bahan Referensi

Folder ini mengelompokkan bahan masukan yang sebelumnya berada langsung di
root workspace.

- `revision/revision.pdf`: dokumen revisi pembimbing tanggal 15 September.
- `source-images/image.png`: gambar referensi yang belum memiliki nama
  deskriptif pada sumber awal.
- `source-images/WhatsApp Image 2026-09-29 at *.jpeg`: tiga gambar asli dosen.

Salinan operasional tiga gambar WhatsApp tetap tersedia di
`DEMO_XAI_745_FULL/06_gambar_revisi/`. File di folder ini dipertahankan sebagai
bahan sumber dan tidak dipakai langsung oleh runtime web demo.
