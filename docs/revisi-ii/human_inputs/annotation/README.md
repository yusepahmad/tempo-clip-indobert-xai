# Anotasi ganda150

Berikan file A dan B kepada dua anotator secara terpisah bersama codebook dan gambar. Jangan memperlihatkan gold atau hasil model. Isi kode persis seperti protocol.json. Jangan berdiskusi sebelum dua file independen dikunci. Setelah keduanya selesai, simpan hasil mentah, jalankan human_agreement.py, lalu lakukan adjudikasi dalam file baru. Kolom kosong berarti belum dinilai, bukan setuju/tidak setuju.
