# E07 VLM few-shot dengan retrieval outer-training

**Tanggal:** 2026-10-10
**Status:** done

## Tujuan
Memperbaiki pemisahan domain sumber melalui contoh supervised dari outer-training, terutama LAINNYA dan HEWAN_TUBUH, setelah E04 Macro-F1 0,5093.

## Ruang Lingkup
- `01_notebook/kaggle_e07/`, kernel private baru dan bukti OOF di learn/Kaggle.
- Memakai sampul, judul/teks asli, deskripsi VLM E01 dan label TRAIN saja sebagai demonstrasi; tidak memakai deskripsi/mapping anotator sebagai input.
- Tidak mengubah dataset atau label.

## Langkah
1. Bentuk split baseline integer seed42, TF-IDF fit hanya outer-training untuk memilih dua contoh terdekat per kelas.
2. Prompt sampel target memuat gambar/deskripsi/judul dan contoh dari outer-training; label target hanya dipakai saat evaluasi akhir.
3. Smoke 12 target OOF untuk integritas prompt, label valid, ID/fold/exemplar disjoint, finite generation, durasi/kuota.
4. Full 740 target setelah smoke teknis dan kuota memungkinkan. Semua contoh/ID/label jawaban/config/prompt hash disimpan agar audit dapat diulang.
5. Hitung OOF pooled/per-fold/per-kelas. Tidak tuning prompt memakai outer-test untuk mengklaim nested hyperparameter selection.

## Risiko & Asumsi
- Supervised few-shot dapat lebih informatif dari zero-shot, belum menjamin 0,70.
- Target label tidak boleh masuk prompt; deskripsi anotator kosong pada NON_METAFORA tidak digunakan.
- Kuota API berbeda dari UI. Push menunggu pemeriksaan kuota dan status E05/E06; tidak mengirim full tanpa smoke.
- Model Qwen3-VL-8B revision sama E01, inferensi greedy, dua T4, maksimal 40 token, gambar sisi768, dua contoh per kelas dipilih dengan aturan tetap.
