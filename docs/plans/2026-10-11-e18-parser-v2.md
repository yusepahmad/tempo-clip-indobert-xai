# E18 parser format eksplisit versi kedua

**Tanggal:** 2026-10-11
**Status:** done

## Tujuan
Mengakui variasi format jawaban kategori eksplisit tanpa menebak label dari alasan bebas. Audit168respons sebelum membaca truth/skor menemukan35format INVALID pada parserv1 (8 respons terpotong); contoh output `Jawab: C`, `Jawab satu kode: E`, dan kode pada baris awal/akhir. Ini perubahan decoding, bukan model/prompt/data.

## Ruang Lingkup
- `DEMO_XAI_745_FULL/01_notebook/e18_hosted/parse_v2.py` dan `evaluate_parsed_v2.py`, output baru `e18_hosted/parsed_v2/`, recovery, plan/changelog.
- Parserv1/evaluatorv1/watch/source worker E18 serta E19/E20 tidak diubah. Tidak ada API call tambahan. Dataset/label asli tetap.

## Langkah
1. Bekukan parserv2 sebelum skor/truth: ambil kode tunggal pada respons/baris pertama/baris terakhir, prefix eksplisit Jawab/Jawaban/Jawab satu kode/Kode, atau kode+kelas yang cocok (di respons/baris pertama/terakhir). Markdown/quotes/titik boleh. JSON dengan code dan opsional label konsisten boleh. Nama kelas tunggal pada respons/baris terakhir boleh.
2. Jika ada beberapa kandidat kode eksplisit berbeda, INVALID; tidak mengekstrak huruf/kategori dari paragraf alasan bebas. Pair kode+label mismatch, JSON ambigu, nama tak dikenal dan respons kosong tetap INVALID.
3. Uji acceptance/rejection/kontradiksi tanpa truth, compile/hash source. Evaluator turunan memakai seluruh740 cache hanya setelah strict verified; simpan skor serta tracev2 terpisah dari strict/v1 dan pin parserhash.
4. Gate sebelumstrict740 tidak menulis metrik. Sesudah lengkap hitung manualF1/sklearn, rootcopy/hash/cek independen sebelum klaim kualitas. Jangan pilih parser berdasarkan skor heldout.

## Risiko & Asumsi
- Perubahan akurasi berasal dari decoding. Format tanpa jawaban eksplisit tidak boleh ditebak dari narasi atau dikoreksi memakai truth.
- Pengenalan format didasarkan output model tanpa label, bukan tuning skor outertest. Tetap laporkan strict/v1/v2 terpisah.

## Verifikasi
Kasus single/markdown/prefix/JSON/firstlast/kelas cocok diterima; multi-kode, label mismatch, JSONunknown, reasononly/BOMB ditolak. Sumber pinned dan output terpisah; gate rejects incomplete; skor hanya all740 plus auditmanual.
