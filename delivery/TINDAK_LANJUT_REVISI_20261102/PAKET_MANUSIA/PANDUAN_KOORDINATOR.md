# Pembagian paket manusia

Kirim ANOTATOR_A.zip dan ANOTATOR_B.zip kepada dua orang berbeda, masing-masing hanya paketnya. Kirim PENILAI_XAI_R1.zip sampai R5 kepada lima penilai independen yang tidak ikut anotasi. Jangan sertakan paket analisis, kunci privat, atau file hasil model kepada anotator/penilai. ADJUDIKASI_60.zip untuk adjudikator, bukan input agreement buta.

Minta persetujuan partisipasi dan catat identitas berkode, tanggal, keahlian, independensi dan versi file secara privat. Tidak ada skor manusia di paket ini. Gabungkan lima ratings.csv tanpa mengubah rater_id setelah diterima; gunakan tools/human_agreement.py pada paket analisis. Jangan mengganti skor kosong dengan nol.
