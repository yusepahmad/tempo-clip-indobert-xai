Penilaian XAI — R5

Nilai sendiri tanpa mendiskusikan skor. Isi ratings.csv dengan bilangan 1–5 menurut rubrik. Ada 16 item dan tiga dimensi per item. Jangan menebak atau mencari identitas metode/kontrol. Simpan file asli setelah selesai.

Peta bersifat visual umum, bukan bukti sebab untuk kelas tertentu. Nilai keterbacaan, relevansi dan bantuan memahami representasi; jangan menganggap area terang membuktikan model benar. Warna lebih terang menandai bobot peta lebih tinggi.
